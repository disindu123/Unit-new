SANGHABODHI COLLEGE MEDIA UNIT PORTFOLIO
========================================

Files
-----
index.html  -> website structure
style.css   -> design, responsive layout, animations
script.js   -> navigation, reveal animations, active section state, inquiry mail composer
media-logo.jpg -> supplied Media Unit logo

CONTACT / INQUIRY SETUP
-----------------------
Open script.js and set:
const INQUIRY_EMAIL = "your-real-email@example.com";

The inquiry form is static-hosting friendly. Submitting the form prepares an email in the visitor's
own mail app using mailto:. No server or database is required.

GALLERY / TEAM
--------------
The gallery cards and leader area are placeholders so real photographs can be dropped in later.
Replace the placeholder blocks in index.html with <img> elements as needed.

RUN
---
Open index.html in a browser, or deploy the folder to GitHub Pages, Netlify, Cloudflare Pages,
Vercel static hosting, or any normal web host.
